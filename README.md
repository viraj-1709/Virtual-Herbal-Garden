🌿 Virtual Herbal Garden

Smart India Hackathon 2026 — AYUSH / Medicinal Plants

An interactive web platform for exploring India's medicinal plants and traditional herbal knowledge through search, plant information, quizzes, gamification, bookmarks, field notes, multilingual support, themes, and a virtual garden experience.

✨ Features

- 🌱 Medicinal plant explorer with images and botanical information
- 🔎 Plant search and discovery
- 🌿 Interactive virtual garden experience
- 🎮 Quizzes and gamification
- ⭐ Save/bookmark plants
- 📝 Digital field notes
- 🌐 Multilingual support architecture
- 🌗 Light/dark themes

🛠️ Tech Stack

- React + JavaScript
- Vite
- Tailwind CSS
- React Context API
- Node.js + npm

🚀 Run Locally

Prerequisites

Install Node.js, npm, and Git.

git clone https://github.com/viraj-1709/Virtual-Herbal-Garden.git
cd Virtual-Herbal-Garden
npm install
npm run dev

Open the local URL shown by Vite, usually "http://localhost:5173/".

Production Build

npm run build
npm run preview
